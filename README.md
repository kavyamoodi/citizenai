# 🇮🇳 Citizen AI

### Government Scheme Recommendation Platform

Citizen AI is a full-stack platform designed to help users discover relevant government welfare schemes based on their eligibility and requirements.

The platform processes user information, evaluates eligibility, and presents relevant scheme recommendations through a simple web interface.

---

## 🚀 Key Features

* **Eligibility-Based Recommendations** — Analyzes user-provided information to identify relevant government schemes.
* **Personalized Suggestions** — Filters schemes based on user requirements and eligibility criteria.
* **Chatbot Assistance** — Provides an interactive way for users to ask scheme-related questions.
* **Scheme Filtering** — Helps narrow down available schemes based on relevant criteria.
* **Frontend–Backend Integration** — Connects the React frontend with backend APIs for dynamic data processing.
* **MongoDB Integration** — Stores and retrieves application data efficiently.

## 🎯 Project Objective

The goal of Citizen AI is to make government welfare schemes easier to discover by reducing the effort required for users to identify schemes that may be relevant to their circumstances.

Instead of manually searching through multiple schemes, users can provide relevant information and receive filtered recommendations through the platform.
