Citizen AI 🇮🇳  
A government scheme recommendation platform that analyzes user data to provide personalized welfare scheme suggestions.

🔥 Features  
User input-based eligibility analysis  
Personalized scheme recommendations  
Chatbot-assisted interaction  
Real-time data processing  
Efficient filtering of schemes  

🛠️ Tech Stack  
Frontend: React.js (Vite)  
Backend: Node.js, Express.js  
Database: MongoDB  
API Integration: REST APIs  

👩‍💻 My Contributions

Implemented data processing and filtering logic for eligibility determination  
Handled API requests, responses, and error handling  
Integrated backend services with frontend for real-time interaction  
Worked with MongoDB for data storage and retrieval
